# Icon sources

- `axiom.svg`: official Axiom logo mark from `https://axiom-assets-v2.axiom-cdn.io/images/axiom-logo-mark.svg`.
- `gmgn.svg`: official GMGN logo from `https://gmgn.ai/static/logo_small2.svg`.

- DEX Screener: DEX Screener brand mark from <https://dexscreener.com/>, geometry verified against the current service mark on 2026-08-11.

The SVG files are stored locally and are not loaded from a runtime CDN.
