# 0003. Функциональные модули backend и независимый Axiom SDK

- Статус: `accepted`
- Дата: `2026-09-27`
- Участники: команда Ascend

## Контекст

Общие api/core/services/repositories/schemas смешивали транспорт, бизнес-правила
и инфраструктуру. HTTP и WS использовали разные валидаторы ключей. SDK-клиент,
WS manager, очередь и кэш создавались глобально, связывая runtime-экземпляры.
Внешние контракты, существующие данные и алгоритмы историй нужно сохранить.

## Решение

Backend состоит из api_keys, token_feed, streaming, token_prices и token_images.
Каждый модуль владеет domain, потребляемыми contracts, сценариями и adapters.
Межмодульные обращения используют публичный пакет; composition может
импортировать реализации для wiring. ORM регистрируется явно в database.
HTTP и WS обращаются к единственному сервису api_keys; pepper внедряется.

SDK находится в third_party_apis/axiom_trade_api, не импортирует app и получает
agents от вызывающей стороны. DTO преобразуются в собственные backend типы.
Base, developer и funding updates остаются отдельными событиями одной пары;
developer и funding selection сохраняют свои различные правила.

Runtime в composition владеет клиентом, кэшами, очередью, менеджером сессий и
задачами. Main управляет startup/shutdown через lifespan. Callbacks снимаются,
задачи отменяются и ожидаются, клиент закрывается и при ошибке startup.

## Последствия

Модули можно тестировать без SDK, БД и web framework, а SDK — без backend.
Два runtime не разделяют application state. Добавление провайдера требует
adapter потребляемого контракта. Известные дефекты и согласованные отличия
WS описаны в [отчёте совместимости](../backend-refactoring.md).

Применённые миграции сохранены побайтно; новый ORM соответствует прежней схеме,
что проверяется Alembic на временной БД. Автоматические проверки границ,
lifespan, staged feed и HTTP → WS входят в pytest.

## Альтернативы

Перенос общих слоёв отдельными этапами оставлял бы новые модули без рабочего
wiring. Выбран последовательный перевод функциональных путей.
Event bus, универсальный repository framework и отдельная сборка SDK не нужны
для существующих границ и не добавлены.
