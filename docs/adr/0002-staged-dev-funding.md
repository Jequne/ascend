# 0002. Поэтапное обогащение Dev Funding

- Статус: `accepted`
- Дата: `2026-09-21`
- Участники: разработчики server и desktop client

## Контекст

`pair-info` сообщает непосредственный funding wallet, но запрос `/portfolio`
через доступные хосты Axiom возвращает `404`. Используемый сервером
`dev-tokens-v5` может вернуть историю для адреса funding wallet, а `token-info`
дает fees прошлых пар. Обогащение нескольких монет создает дополнительные HTTP
вызовы и может задержать новое событие при ограничении частоты Axiom.

## Решение

Источником истории Dev Funding служит `dev-tokens-v5` с адресом funding wallet
как `devAddress`. История ограничена тремя предыдущими монетами; fees берутся из
`token-info`. Базовое событие и результат funding-обогащения передаются двумя
полными сообщениями `token_feed` с тем же адресом пары. Клиент обновляет
существующую карточку и выполняет уведомление и автооткрытие только при первом
принятии пары.

Все HTTP-запросы одного клиента Axiom проходят через общий ограничитель
частоты и параллелизма. Новые события имеют приоритет перед необязательным
обогащением истории. Одновременные запросы истории одного funding wallet
объединяются, а успешные ответы истории, `pair-info` и `token-info` кратко
кешируются по адресу. `429` охлаждает маршрут по
`Retry-After`; число повторов и общее ожидание ограничены.

## Последствия

Доступный колл может появиться до завершения funding-обогащения; поздний
результат добавляет индикатор в ту же карточку. Клиенту требуется помнить уже
полученные пары, сохранять подтвержденную funding-историю при повторном базовом
сообщении и не повторять пользовательские действия. Отдельный endpoint
`/portfolio` не нужен. История Axiom для funding wallet не доказывает полноту
всех запусков, профинансированных этим адресом; область стратегии ограничена
тем, что возвращает `dev-tokens-v5`.

## Альтернативы

- Ожидать все запросы до первой отправки: задерживает доступный колл при
  ограничениях Axiom.
- Использовать `/portfolio`: доступный маршрут не подтвержден и возвращает
  `404`.
