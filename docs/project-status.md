# Текущее состояние

Срез актуален на 27 сентября 2026 года и описывает текущее состояние файлов
репозитория. Этот документ фиксирует реализованное, а не обещанный roadmap.

## Реализованный контур

| Область      | Состояние                                                                                                                     |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| Поток данных | Сервер получает данные Axiom, обогащает события и передает их клиентам через WebSocket                                        |
| Доступ       | Есть создание и проверка API-ключей, срок действия, отзыв, лимит активных сессий и периодическая повторная проверка WebSocket |
| Desktop      | Svelte-интерфейс работает в Tauri, валидирует сообщения, хранит настройки локально; интерфейс адаптирован к ширине 250 px       |
| Уведомления  | Принятые колы запускают стандартный или пользовательский звук; Blob хранится в IndexedDB, метаданные — в настройках V5          |
| Автооткрытие | Поддержаны режимы `off`, `new_tab` и `current_axiom_tab`                                                                      |
| Расширение   | Manifest V3-расширение связывается с Tauri по loopback WebSocket и управляет заранее выбранной вкладкой Axiom                 |
| Данные       | SQLite используется по умолчанию локально, PostgreSQL 16 — в Docker Compose; схема управляется Alembic                        |
| Эксплуатация | Есть Caddy/TLS, Grafana, Loki, Alloy и Restic backup в S3-совместимое хранилище                                               |
| Тесты        | Для client и extension есть Vitest; для extension — Playwright; для Rust — cargo test; для server — pytest                    |
| Backend | Функциональные api_keys/token_feed/streaming/token_prices/token_images, независимый Axiom SDK, Runtime composition; Ruff/mypy/pytest закреплены |

## Известные ограничения

- Полная ручная smoke-матрица установленного расширения для Chrome, Edge и Brave
  не автоматизирована. Автоматический regression gate использует Chromium;
  детали собраны в [отчете QA](../src/extension/QA.md).
- Сохранённые дефекты ключей и WS (revoked_at, session race, DB outage watchdog)
  описаны в [отчёте рефакторинга backend](backend-refactoring.md).
- CI-конфигурация в репозитории отсутствует; проверки выполняются локально.
- Очередь серверных событий находится в памяти, поэтому горизонтальное
  масштабирование потребует отдельного брокера или другого общего транспорта.

## Как вести раздел дальше

При начале заметной инициативы добавьте краткий пункт в раздел «В работе» с
ссылкой на issue или ADR. После завершения перенесите результат в таблицу выше,
удалите закрытое ограничение и укажите новые ограничения, если они появились.
