# Документация Ascend

Этот каталог — источник актуальной технической документации проекта. Корневой
README дает только обзор и быстрый старт; детали должны находиться здесь.

## Навигация

| Документ                               | Что в нем зафиксировано                          | Когда обновлять                            |
| -------------------------------------- | ------------------------------------------------ | ------------------------------------------ |
| [Текущее состояние](project-status.md) | Реализованный контур и известные ограничения     | При изменении возможностей или приоритетов |
| [Архитектура](architecture.md)         | Компоненты, границы, зависимости и потоки данных | При изменении модулей или интеграций       |
| [Разработка](development.md)           | Локальный запуск, тесты и quality gates          | При изменении команд или инструментов      |
| [Аутентификация](authentication.md)    | API-ключи и защита WebSocket                     | При изменении модели доступа               |
| [База данных](database.md)             | Хранилища, схема и миграции                      | При изменении модели данных                |
| [Развертывание](deployment.md)         | Production-топология, конфигурация и backup      | При изменении инфраструктуры               |
| [ADR](adr/README.md)                   | Причины значимых архитектурных решений           | До или вместе со значимым решением         |

## Правила оформления

- Один документ отвечает за одну тему и начинается с заголовка первого уровня.
- Используются стандартный Markdown, относительные ссылки и Mermaid для схем.
- Команды должны копироваться и запускаться из указанного каталога.
- Секреты, реальные fingerprints, API-ключи и приватные данные не публикуются.
- Факты о текущей реализации отделяются от планов и предложений.

Правила обязательного сопровождения документации описаны в
[корневом `AGENTS.md`](../AGENTS.md).
